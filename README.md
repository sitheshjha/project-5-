✈️ Flight Booking Analytics & Price Intelligence Dashboard

📌 Project Overview

The Flight Booking Analytics & Price Intelligence Dashboard is an end-to-end Data Analytics project developed using PostgreSQL and Power BI to analyze airline pricing trends, booking behavior, route performance, flight durations, and stop patterns.

This project transforms raw flight booking data into actionable business insights through SQL analytics and interactive visual dashboards. The dashboard helps understand customer travel behavior, airline pricing strategies, and operational trends across multiple airlines and routes.

---

🚀 Objectives

- Analyze airline ticket pricing patterns
- Identify high-cost and low-cost travel routes
- Study the impact of stops and duration on ticket prices
- Compare business and economy class pricing
- Create interactive business intelligence dashboards
- Generate actionable insights for airline analytics

📈 Key Business Insights

- Flights booked closer to departure dates generally have higher ticket prices.
- Business class flights contribute significantly higher revenue compared to economy class.
- Multi-stop flights tend to have lower average prices than direct flights.
- Certain airline routes consistently show premium pricing trends.
- Flight duration has a strong impact on pricing behavior.

⚡ How to Run the Project

Step 1 — Database Setup

- Install PostgreSQL
- Create database:

CREATE DATABASE flight_analytics;

Step 2 — Import Dataset

- Create flights table
- Import CSV dataset into PostgreSQL

Step 3 — Run SQL Queries

Execute SQL scripts from:

sql_queries/analysis_queries.sql

Step 4 — Connect Power BI

- Open Power BI
- Connect to PostgreSQL database
- Load flights table

Step 5 — Build Dashboard

Use Power BI visuals and DAX measures to create interactive dashboards.
